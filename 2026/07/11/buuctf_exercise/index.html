ciscn_2019_n_1

查看保护机制：

64 位程序，开启栈不可执行；

用 IDA 查看反编译代码：

main 函数先进行初始化，然后调用函数 func()；

跟进函数 func()：

读取输入 v1，如果 v2==11.28125，则打印输出 flag；使用 gets() 读取输入，存在栈溢出漏洞；

对应汇编代码：

我们可以通过溢出，将 v2 的值覆盖为 11.28125 或者将返回地址覆盖为 return system("cat /flag"); 的地址，获取 flag

这里采用第二种方法，偏移：0x30 + 8 = 56 字节

拿到 flag：CTF2{9a0db5e5-24e7-4a43-9186-e322e4b2094e}

如果是另外一种方法，先找到 11.28125 的 16 进制（即图中 0x41348000）

偏移：0x30 - 0x4 = 44 字节

一样能拿到 flag

【已停止提交】ret2libc

怎莫没有后门函数惹，不响丸辣！

查看保护：

64 位程序，开启栈不可执行；

main 函数先调用 init() 函数初始化，然后用 puts() 函数打印提示词，用 fgets() 读取输入到 s，然后用 puts() 打印再见，程序结束；显然，读取 96 字节的数据到 32 字节的 s 上，存在栈溢出漏洞；

没有在程序中发现后门函数，也没有找到 system() 函数和 /bin/sh 的地址，显然是 ret2libc 了；

第一次栈溢出先泄露 puts() 函数的真实地址，计算出 libc 的基地址（题目给了 libc 版本就不需要再用 libcSearcher 获取 libc 版本了），再获取 system() 函数的地址与 /bin/sh 的地址，然后再次返回源程序，第二次栈溢出执行 system(‘/bin/sh’); 拿到shell；

偏移：0x20 + 8 字节；

选取 gadget 构造 rop 链、实现栈对齐：

exp：

拿到 flag：CTF2{6cb95ba6-18bf-4613-962b-849a54d1f10f}

【已停止提交】fallw1nd’s gift

这算个毛gift！怎么是puts函数啊！

查看保护：

64 位程序，开启栈不可执行、影子栈和间接跳转跟踪；

用 IDA 查看反编译代码：

main 函数先调用 init() 初始化，调用 puts() 输出提示信息，再调用 printf() 输出 puts() 函数的真实地址；然后读取输入的地址并存入 buf（buf[0] ），再调用 read() 读取输入并写入 buf[0] 所指向的地址 ，然后调用 puts() 输出 /bin/sh 字符串；

考虑将 puts() 函数的 got 表项地址覆盖为 system() 函数的地址，使 puts(“/bin/sh”) 变成 system(“/bin/sh”)，就可以拿到 shell；这里先传入 puts() 的 got 表项地址，再传入 system() 函数的地址，puts() 函数的 got 表项地址就会被覆盖为 system() 函数的地址，程序执行 puts(“/bin/sh”) 时实际上就会执行 system(“/bin/sh”)；

exp：

拿到 flag：CTF2{495e8595-e0de-4648-b3e1-3502c73e6607}

【已停止提交】ezshellcode

shellcode第一弹!写点什么来getshell吧!

查看保护：

64 位程序，开启栈不可执行、影子栈和间接分支跟踪；

用 IDA 查看反编译代码：

main 函数先调用 init() 函数初始化，再调用 mmap() 函数分配一块具有可读可写可执行权限的起始地址为 0x66660000 的内存给 buf，然后调用 puts() 函数打印提示信息，用 read() 函数读取 0x100（256）字节，并直接存入 buf（即刚才 mmap() 函数分配的位于 0x66660000 的内存）中，最后让 CPU 直接跳转到 0x66660000 去执行；

显然，只需要向 buf 中直接写入 shellcode 即可，没有一点弯子；

exp：

拿到 flag：CTF2{bff00874-6105-43a1-bf00-c561c1b0385e}

【已停止提交】ret2shellcode

shellcode 是什么，壳码？怎莫会事呢？

查看保护：

64 位程序，开启栈不可执行和地址随机化；

用 IDA 查看反编译代码：

main 函数先调用 init() 函数进行初始化，然后调用 mmap() 函数分配一块具有可读可写可执行权限的起始地址为 0x233000 的内存给 buf，接着打印提示信息，读取输入的 0x100 字节的数据到 buf，再打印提示信息，读取 0x100 字节的数据到 v4，最后打印再见，程序结束；

显然，只需要向 buf 写入 shellcode，再通过 v4 进行栈溢出返回 buf 的地址即可拿到 shell；由于分配给 buf 的地址固定，地址随机化在这里实际上没有什么影响；

偏移：0x30 + 8 字节；

exp：

拿到 flag：CTF2{c78a927f-3474-4c54-b808-d4397d4b60f1}

bjdctf_2020_babystack2

查看保护：

64 位程序，开启栈不可执行；

用 IDA 查看反编译代码：

main 函数先初始化，再打印欢迎和提示信息，然后读取用户输入存入 nbytes，并转换 nbytes 的类型为整型与 10 比较，大于 10 则退出；接着再打印提示信息，将 nbytes 转换为无符号整型，读取 nbytes 字节的数据到 buf上，最后程序结束；

发现后门函数 backdoor()，它直接调用一个 shell；

显然，只需要将返回地址覆盖到后门函数的地址即可；如果输入一个负数给 nbytes，如 -1，(int)nbytes 就是 -1，不大于 10，顺利通过，(unsigned int)-1 就是 0xFFFFFFFF，从而可以读取超长数据，造成栈溢出；

偏移：0x10 + 8 字节；

exp：

拿到 flag：CTF2{74ae55bf-8337-4a02-8344-bfacf916fdb4}
